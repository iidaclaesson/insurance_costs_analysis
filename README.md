# insurance_costs_analysis


## Körinstruktion
Öppna filen insurance_costs_analysis.Rmd i RStudio.

**Paket som används**
Installera paketen:
```
install.packages("tidyverse")
install.packages("skimr")
install:pacakges("patchwork")
```

**Kör igång analysen**
Klicka på Knit i RStudio för att rendera dokumentet, då skapas en HTML-fil automatiskt i samma mapp.
